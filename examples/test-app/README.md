# TestGenesis Test App

A simple NiceGUI application with Amplitude tracking to help test and demonstrate TestGenesis functionality.

## Features

- 🔐 User Authentication Flow
  - Login form with validation
  - Registration form
- 🛒 Shopping Cart Flow
  - Product listing
  - Add to cart
  - Checkout process
- 📝 User Profile Flow
  - View profile
  - Update settings

## Amplitude Events

The app tracks the following events:

### Authentication Events
- `page_view` - When user visits any page
- `form_submit` - When user submits any form
- `login_success` - When login is successful
- `login_error` - When login fails
- `signup_start` - When user starts registration
- `signup_complete` - When registration is successful

### Shopping Events
- `product_view` - When user views a product
- `add_to_cart` - When user adds item to cart
- `remove_from_cart` - When user removes item from cart
- `checkout_start` - When user starts checkout
- `checkout_complete` - When purchase is completed

## Setup

```bash
# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install uv if not already installed
pip install uv

# Install dependencies (will automatically generate uv.lock)
uv sync

# Set up environment variables
cp .env.example .env
# Add your Amplitude API key to .env

# Run development server
python app.py
```

## Updating Dependencies

To update dependencies to their latest compatible versions:

```bash
uv sync --upgrade
```

## Generating Test Data

1. Run the app locally
2. Use the app normally, performing various user flows
3. Check Amplitude dashboard to see events
4. Use TestGenesis to extract flows:
   ```bash
   testgenesis amplitude extract-flows \
     --api-key your-amplitude-api-key \
     --start-date 2024-03-01 \
     --end-date 2024-03-31 \
     --output-dir ./test_flows
   ```
